# Birthday DVD Bouncer

A small HTML birthday animation featuring three bouncing images, falling confetti, and a simple clean design.

## Preview

The page displays:

**HAPPY BIRTHDAY PERSON!**

while three copies of the selected image bounce around the screen like classic DVD logos.

## Features

* 3 independently moving images
* DVD-style bouncing
* Rotation and tilt when hitting the edges
* Falling confetti
* White background
* Figtree font
* Responsive sizing
* No frameworks
* Pure HTML, CSS and JavaScript

## Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/birthday-dvd-bouncer.git
cd birthday-dvd-bouncer
```

Then open:

```text
index.html
```

in your browser.

No build process is required.

## Project Structure

```text
birthday-dvd-bouncer/
├── index.html
└── README.md
```

## Customization

The birthday message can be changed in `index.html`:

```html
<div class="title">HAPPY BIRTHDAY PERSON!</div>
```

The bouncing image can also be changed by replacing the image URL in the JavaScript.
